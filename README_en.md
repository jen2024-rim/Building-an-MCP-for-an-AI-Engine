# Building an MCP for an AI Engine 🚀

This repository documents my progress through **Building an MCP for an AI Engine** , hands-on cohort by [NxtFlows Academy](https://nextflows.ai/academy/portal/dashboard) for 4th and 5th year Computer Science and Computer Engineering students. Over six weeks, the goal is to go from "what's an MCP?" to a working MCP server, connected to an AI engine like Claude, fully documented, and live on GitHub.

## 🧭 Program Overview

The program is split into progressive modules, each unlocked after completing the previous one:

- [ ] **1. What is MCP?**
  An introduction to the Model Context Protocol (MCP) — what it is, why it matters, and the foundational concepts you'll build on for the rest of the program.
- [ ] **2. Design your own tools**
  Pick a starter project, design a clear tool surface, and implement a multi-tool server skeleton with solid schemas.
- [ ] **3. Connect your tools to real data**
  Connect your tools to real data sources.
- [ ] **4. Make it safe & reliable**
  Harden the server's safety and reliability.
